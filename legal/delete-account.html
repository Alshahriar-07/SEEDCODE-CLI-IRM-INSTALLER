SeedCode CLI: Account & data
deletion.

Last updated: 5 November 2026. SeedCode CLI has no hosted SeedCode account in this release, so deletion means removing local data and revoking your provider keys.

1. There is no SeedCode account server

This release does not create a SeedCode account or store your data on a SeedCode server. There is therefore no remote profile to delete. If a future release adds a hosted login, this page will describe the remote deletion process before that feature ships.

2. Delete local CLI data

Close every running SeedCode CLI session, then delete its configuration folder:

  • Windows — rmdir /s /q "%USERPROFILE%\.seedcode"
  • Linux / macOS — rm -rf ~/.seedcode

This removes provider settings, saved API keys, session history and local caches. It does not touch your projects.

3. Delete project memory

If you used project memory, delete the .seedcode folder inside each project you worked on. Nothing else in your repository is modified by the CLI's own storage.

4. Revoke provider credentials

  • OpenRouter — delete the key in your OpenRouter account dashboard.
  • GitHub / GitHub Copilot — review and revoke authorised OAuth apps and personal access tokens in your GitHub account settings. Removing the key locally does not revoke it at GitHub.
  • AeroLink / FreeModel — delete the key in that provider's dashboard.
  • Custom endpoints — revoke the key with whoever issued it.
  • Ollama — local only; no key to revoke.

5. Environment variables

If you exported keys in a shell profile, CI secret store or .env file, remove them there as well; deleting the CLI configuration does not clear environment variables.

6. Request help with deletion

If you believe the project holds data about you, email github@eagox.studio with the subject "Data deletion request" and a description of what you believe is held. You will receive a response confirming what exists and what has been removed. The project will not invent a statutory deadline it cannot meet.
