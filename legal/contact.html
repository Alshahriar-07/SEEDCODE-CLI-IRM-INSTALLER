Support

SeedCode CLI: Contact &
support.

SeedCode CLI is maintained by Al Shahriar Sowan. These are the real channels for help.

Bug reports and feature requests

Open an issue with the version, operating system, the command you ran and the exact error text: github.com/Alshahriar-07/seedcode-cli/issues. Remove API keys, tokens and private code from logs before posting.

Documentation first

The install guide, provider guide and command reference cover the common setup problems. Run /doctor inside the CLI for a local diagnostic of your provider, workspace and environment.

Security reports

Do not file a public issue for an unpatched vulnerability. Use the private report link on the security page.

Legal, privacy and data deletion

Email github@eagox.studio for questions about the terms, the privacy policy, the acceptable use policy, or to request deletion of any data you believe the project holds. See account and data deletion for the local steps you can take immediately.

Support expectations

This is an independent project. Support is provided on a best-effort, community basis; no response time, uptime or fix guarantee is offered. Provider problems (billing, model access, account suspension) must be raised with that provider, not with SeedCode.
