SeedCode CLI: Privacy
Policy.

Last updated: 5 November 2026. This policy covers the SeedCode CLI application and this website.

1. Scope and operator

SeedCode CLI is a local command-line application developed by Al Shahriar Sowan and published under Eagox Studio. It is not a hosted service: there is no SeedCode account database and no SeedCode server that receives your project files in this release.

2. Data the CLI handles

  • Configuration — provider choice, model, theme, workspace history and settings, stored locally in ~/.seedcode/ (Windows: %USERPROFILE%\.seedcode).
  • Credentials — API keys you enter, stored locally in that configuration file with restricted file permissions, or supplied through environment variables.
  • Prompts and project context — the text you submit and the files the agent reads are sent to the AI provider you configured, because that is how the model answers.
  • Command output — terminal output stays on your machine, except for the excerpts included in a request to your provider.
  • Project memory — an optional local index under .seedcode/ inside your project.

3. What SeedCode does not collect

The CLI does not include analytics, telemetry or crash-reporting code. It does not send your prompts, files, keys or usage data to the author. This website is a static site and sets no advertising or tracking cookies of its own; it loads fonts from Google Fonts, which receives the usual request information (such as your IP address) under Google's policies.

4. Token and credential handling

Keys are never logged, never printed in full, and never transmitted to SeedCode. They are used only to authenticate requests to the provider that owns them. Environment variables are supported for CI and headless use. You should still treat your configuration file as sensitive and remove keys you no longer need.

5. Third-party providers

When you select a provider, your prompts, relevant project context and credentials for that provider are sent to it. This includes OpenRouter, Ollama (local, no transfer off your machine), GitHub Copilot, AeroLink, FreeModel and any custom endpoint you add. Each provider processes data under its own privacy policy. SeedCode cannot control and is not responsible for that processing. Review each provider's policy before sending confidential code.

6. Data processing and retention

SeedCode retains nothing remotely because it stores nothing remotely. Local configuration and project memory remain until you delete them. Your provider's retention of prompts and responses is governed by that provider's policy. Session history saved by the CLI stays on your machine.

7. Security practices

The CLI restricts configuration file permissions where the operating system supports it, redacts credentials from logs and error messages, and asks for approval before destructive actions in its default permission mode. No system can be guaranteed secure; you are responsible for protecting your machine and accounts.

8. Your rights

Because the author holds no personal data about CLI users, there is no remote profile to access, correct or port. You control all local data directly. You may also request information about this policy by contacting the address below.

9. Data deletion

Delete the local configuration folder, any project .seedcode folders and your saved sessions to remove CLI data, then revoke the API keys you created with each provider. Step-by-step instructions are on the account and data deletion page.

10. Children

SeedCode CLI is a developer tool and is not directed at children. Do not use it if you are not old enough to accept these terms under your local law.

11. Changes and contact

This policy may be updated; the current version and date are always on this page. Questions or deletion requests: github@eagox.studio or the issue tracker.
