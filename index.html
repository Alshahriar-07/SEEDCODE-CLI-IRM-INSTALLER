Changelog — v8.2.5

      
0 tests passing

    

    

      

        
Agent Mode, unified

        
    
          
  • Two modes, not three — Chat and Agent. /mode code, /codemode, /assist, and /desktop now all resolve to Agent Mode.
    • 
          
  • /agent on carries Code Mode's old powers with it: .seedcode memory + index and the persistent plan → execute → verify loop.
    • 
          
  • Agent Mode reads, edits, and searches files, runs terminal commands, installs deps, and iterates on failing tests on its own.
    • 
        

      

      

        
Interface & performance

        
    
          
  • Mode-switch freeze and flicker fixed at the root — the terminal app is built once and re-entered, not rebuilt per switch.
    • 
          
  • A bounded permission panel handles allow/deny in place: Enter allows, A allows for the session, D denies, Esc cancels.
    • 
          
  • Streamed replies now update only the conversation region — the logo, header, and input box stay put.
    • 
        

      

      

        
Release

        
    
          
  • Providers, models, shortcuts, history, and project memory all carry over untouched.
    • 
          
  • Docs, wheel, sdist, npm tarball, and the Windows installer are rebuilt with fresh, verified SHA256 checksums.
    •
