    OPEN SOURCE AI CODING AGENT
  


  

    Install SeedCode Cli
  

  

    An advanced open-source AI coding agent that lives in your terminal. Pick your OS and run one command to get started.
  


  
  

    

      
      
      
      
      
    


    
    

      

        
PowerShell (IRM)

        Windows 10/11
      

      

        irm https://seedcode-cli.vercel.app/install.ps1 | iex
        
      

    


    
    

      

        
Terminal (curl)

        macOS
      

      

        curl -fsSL https://seedcode-cli.vercel.app/install.sh | bash
        
      

    


    
    

      

        
Bash (curl)

        Linux
      

      

        curl -fsSL https://seedcode-cli.vercel.app/install.sh | bash
        
      

    

    
    

      

        
pip (PyPI)

        Python 3.12+
      

      

        pip install seedcode-cli
        
      

      
Requires Python 3.12 or newer.
